### Check out the New Digs!

**I've been pretty quiet here for the last few weeks** because work has been tiring enough that creative endeavors were pretty well ruled out. I'm hoping to reset my efforts here, and part of that is this new space. I new the previous blog was going to be temporary when I realized the settings were very minimal without really digging into the trenches of HTML. I have some technical skills, but I do not really want to manage all that. I've gotten to like the simplicity of the set up I've been using, so choosing a different theme that has some easy configuration options has allowed me to do that. 

It took a few weeks but I got there. 

I have some ideas for new posts, which will be up coming. I also added an email option and mastodon, so if you want to you can now send me a message. I'm debating adding a chat feature, but I don't want to get into more overhead that will take away from writing.
